# Contributing to CyberScape

Thank you for contributing! We welcome issues, PRs, and discussions.

## Quick Start
```bash
git clone https://github.com/shivang-jindal/CyberScape.git
cd CyberScape
npm install
npm run dev
```

## Development
- **Code style**: ESLint + Prettier (run `npm run lint` and `npm run format`)
- **Types**: Strict TypeScript (`npm run typecheck`)
- **Tests**: Vitest (`npm test`)
- **Commits**: Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`)

## Pull Requests
1. Fork & branch from `main`
2. Write tests for new behavior
3. Ensure `npm run verify` passes
4. Open PR with clear description

## Issues
Use templates: Bug Report, Feature Request, Security, Question.
